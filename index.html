Selected work

  • The Critical Realism Threshold

    Research with Evan Petersen and Muhammad Lutfor Rahman

    How much visual realism does synthetic driving data need before it stops helping real-world perception? We trained detectors on three simulators (Synscapes, UrbanSyn and RealDriveSim) under matched data budgets to find out.

    PyTorch, Ultralytics YOLO, OpenCV, MLflow, Weights & Biases

    Read more on the projects page

  • CaseLight

    Swans Applied AI Hackathon, October 2026

    Reads a personal-injury case from Clio and turns every note, email and document into a 90-second brief for the attorney, plus a separate view for the providers treating the client.

    Node.js, Claude API, Docker

    View the code on GitHub

  • YT Analytics Studio

    Personal project

    Two exploratory Jupyter notebooks rebuilt as a web app for YouTube channel analytics: calendar heatmaps of views, tag scores that compare top and bottom performers, and how video length relates to views.

    Python, Flask, pandas, React, Recharts

    View the code on GitHub
